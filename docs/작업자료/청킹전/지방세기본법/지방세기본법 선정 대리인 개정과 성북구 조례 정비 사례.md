# 지방세기본법 선정 대리인 개정과 성북구 조례 정비 사례

## 개요

2024년 12월 지방세기본법·시행령 개정(2025.1.1 시행)으로 선정 대리인 제도가 영세 법인까지 확대되고 시행령 항 번호가 바뀌었으며, 성북구는 약 9개월 뒤인 2025.9.25에 관련 조례 2개를 정비했다.

- 법령: 지방세기본법 제93조의2, 같은 법 시행령 제62조의2
- 자치법규: 서울특별시 성북구 구세 기본 조례, 서울특별시 성북구 납세자보호에 관한 사무처리 조례
- 활용 목적: 법령개정 알리미 시연에서 "상위법 개정 → 영향받는 조례 탐지 → 인용 조문 불일치 경고" 흐름을 보여주는 사례

## 제도 개요

지방자치단체 선정 대리인은 지방세 과세전적부심사나 이의신청을 하는 납세자에게 지자체가 변호사·세무사·공인회계사를 무료 대리인으로 선정해 주는 제도로, 2019.12.31 지방세기본법 제93조의2로 신설됐다.

| 단계 | 근거 | 정하는 내용 |
| --- | --- | --- |
| 법률 | 지방세기본법 제93조의2 | 신청 자격의 큰 틀 (소득·재산, 체납 여부, 청구금액, 제외 세목) |
| 시행령 | 지방세기본법 시행령 제62조의2 | 구체적 기준 금액, 대리인 선정 주체, 조례 위임 범위 |
| 조례 | 성북구 조례 | 재산 평가 방법, 신청·통지 절차, 대리인 의무·우대·수당 |

구청장은 서울특별시장이 미리 위촉한 사람 중에서 대리인을 선정한다.

## 법률 개정: 지방세기본법 제93조의2

법률 제20629호(2024.12.31 공포, 2025.1.1 시행)는 "법인이 아닐 것" 요건을 삭제하고, 매출액·자산이 일정 금액 이하인 법인도 대리인을 신청할 수 있게 했다.

| 조항 | 개정 전 (시행 2024.7.1) | 개정 후 (시행 2025.1.1) |
| --- | --- | --- |
| 제1항 제1호 | 종합소득금액과 소유 재산의 가액이 각각 대통령령으로 정하는 금액 이하일 것 | 가. 개인: 종합소득금액과 소유 재산 가액이 대통령령 금액 이하 / 나. 법인: 기업회계기준 매출액과 자산이 대통령령 금액 이하 |
| 제1항 제2호 | 법인(법인으로 보는 단체 포함)이 아닐 것 | 삭제 |
| 제1항 제3호 | 고액·상습 체납자 등이 아닐 것 | 변경 없음 |
| 제1항 제4호 | 대통령령으로 정하는 금액 이하인 청구 또는 신청일 것 | 변경 없음 |
| 제1항 제5호 | 담배소비세, 지방소비세, 레저세가 아닌 세목일 것 | 변경 없음 |
| 제2항~제4항 | 7일 내 선정·통지, 대리인 권한, 운영은 대통령령 | 변경 없음 |

## 시행령 개정: 제62조의2

대통령령 제35175호(2024.12.31 공포, 2025.1.1 시행)는 법인 기준을 제3항으로 신설하면서 뒤의 항 번호를 하나씩 밀었고, 이것이 조례 인용 조문에 영향을 줬다.

| 항목 | 개정 전 (시행 2024.7.1) | 개정 후 (시행 2025.1.1) |
| --- | --- | --- |
| 개인 소득 기준 | 종합소득 5천만원 (배우자 소득 포함) | 종합소득 5천만원 (배우자 합산 삭제) |
| 개인 재산 기준 | 5억원 (배우자 재산 포함, 조례로 5억원 이하 조정 가능) | 5억원 (배우자 합산 삭제, 조례 조정 가능 유지) |
| 법인 기준 | 없음 | 매출액 3억원, 자산가액 5억원 이하 (제3항 신설) |
| 고액·상습체납자 정의 | 제3항 | 제4항 (내용 동일) |
| 청구금액 상한 | 제4항, 1천만원 | 제5항, 2천만원 |
| 대리인 선정 주체 (시·도지사 위촉자 중 선정) | 제5항 | 제6항 |
| 조례 위임 (재산 평가, 임기·위촉, 신청 절차) | 제6항 | 제7항 |

개정 후 제5항은 "청구금액 2천만원" 기준이 되어, 종전 "제5항"을 인용하던 조례는 엉뚱한 조항을 가리키게 됐다.

## 성북구 조례 개정

성북구는 조례 제1714호(2025.9.25 시행) 한 건으로 두 조례를 함께 고쳐, 선정 대리인 조항을 구세 기본 조례에서 납세자보호 조례로 옮기고 시행령 인용 항을 바로잡았다.

| 조례 | 개정 전 (2024.5.9, 제1595호) | 개정 후 (2025.9.25, 제1714호) |
| --- | --- | --- |
| 구세 기본 조례 제6조 | 소유 재산 평가: 영 제62조의2제2항제2호 재산은 지방세법 제4조, 같은 법 시행령 제3조·제4조에 따름 | 삭제 |
| 구세 기본 조례 제7조 | 선정대리인 신청·통지 (제2항: "영 제62조의2제5항에 따라" 서울시장 위촉자 중 선정) | 삭제 |
| 구세 기본 조례 제8조 | 선정대리인 의무·우대 (사건 계속 수행, 비밀유지, 표창, 실비 수당) | 삭제 |
| 납세자보호 조례 | 납세자보호관 업무에 선정 대리인 없음 | 납세자보호관 업무에 "선정 대리인의 운영에 관한 사항" 신설 |
| 납세자보호 조례 제10장 | 없음 | 제37조(재산 평가방법), 제38조(신청·통지, "영 제62조의2제6항"), 제39조(의무·우대·수당) 신설 |
| 납세자보호 조례 제40조 | 제37조(시행규칙) | 제37조에서 제40조로 이동 |

옮겨진 조문 내용은 거의 같고, 달라진 것은 소관(세무부서 → 감사담당관의 납세자보호관)과 인용 항 번호(제5항 → 제6항)다. 법인 확대와 금액 기준은 법률·시행령이 직접 정하므로 조례에는 따로 반영되지 않았다.

## 법령개정 알리미 시연 포인트

이 사례는 "새 내용 추가"가 아니라 "형식 정비 누락"을 잡아내는 기능을 보여주기에 좋다.

1. 상위법 개정 탐지: 2025.1.1 시행령 제62조의2 개정을 수집하고 항 번호 이동을 감지한다.
2. 영향 조례 매칭: 조례 본문에서 "영 제62조의2"를 인용하는 성북구 자치법규를 찾는다 (구세 기본 조례 제6조·제7조).
3. 인용 조문 대조: 제7조 제2항이 인용한 "제5항"의 내용이 선정 주체에서 청구금액 기준으로 바뀐 것을 경고한다.
4. 정비 결과 확인: 2025.9.25 개정으로 해소됐음을 표시하고, 불일치 기간(약 9개월)을 보여준다.
5. 복수 조례 영향: 한 번의 법령 개정이 조례 2개에 동시에 반영된 점을 보여준다.

알림 예시:

> 지방세기본법 시행령 제62조의2 개정 (2025.1.1 시행): 항 번호가 변경되었습니다. 영향받는 자치법규: 서울특별시 성북구 구세 기본 조례 제7조 제2항 ("영 제62조의2제5항" 인용) 검토 필요: 인용 조문을 "제6항"으로 정비. 참고로 개정 후 제5항은 청구금액 상한(2천만원) 규정입니다.
